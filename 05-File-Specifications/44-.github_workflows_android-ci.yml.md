# File specification: `.github/workflows/android-ci.yml`

**Purpose:** GitHub Actions pipeline.

## Required implementation
Push/PR/workflow_dispatch; JDK compatible with Gradle; cache; format/lint/unit tests/assembleDebug; upload APK artifact; least privilege; no release secrets.

## Acceptance criteria
- Matches the architecture, data contracts and feature catalogue.
- Handles null/empty/error states explicitly.
- Has no unrelated responsibilities.
- Includes or is covered by relevant tests.
- Compiles with the pinned compatible dependency versions.
