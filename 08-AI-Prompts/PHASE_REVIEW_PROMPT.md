# Phase review prompt

Review the completed JobMate phase against the specifications without rewriting the project. Check acceptance criteria, package/interface consistency, Room source-of-truth behavior, coroutine/transaction correctness, credential/resume/screenshot privacy, one-recipient-per-email isolation, user capture consent, safe retries, meaningful tests and CI compilation. Return blockers/high/medium/low defects with exact paths and minimal fixes. Ask if behavior is unspecified.
